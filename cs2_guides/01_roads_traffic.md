# 01 — Roads & traffic (brief)

**Deep rules:** [`../TRAFFIC_GUIDE.md`](../TRAFFIC_GUIDE.md) — hierarchy, signals, roundabouts, interchanges, parking, trucks, transit-for-traffic, diagnosis order. **Do not re-derive those here.**

## Claude quick checklist (Barney / Ephrata)
1. Classify roads as highway / arterial / collector / local before placing. [TRAFFIC][S06–S09]
2. Connect each class only to neighbors in the hierarchy. Flag real Ephrata exceptions. [TRAFFIC]
3. Space arterial junctions; avoid large four-ways; prefer T-junctions / slip roads / roundabouts wisely. [TRAFFIC]
4. Never dump a highway into a roundabout; merge before split; add merge capacity. [TRAFFIC / Real Civil Engineer]
5. After roads: give the user a signal / stop-sign / median / lane-connector checklist. [TRAFFIC]
6. Diagnose traffic from the jam's head; change one thing at a time. [TRAFFIC]
